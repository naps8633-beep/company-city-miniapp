COMPANY CITY — MINI APP (BASE DE DÉPART)

Ce dossier contient :
- l'image d'accueil exacte fournie par toi : public/accueil-company-city.jpg
- une application React/Vite de départ
- une navigation de démonstration Accueil / Boutique / Promotions / Panier / Compte

Pour lancer sur ordinateur :
1. Installer Node.js (version LTS).
2. Ouvrir un terminal dans ce dossier.
3. Exécuter : npm install
4. Exécuter : npm run dev
5. Ouvrir l'adresse locale affichée par Vite.

Pour l'ouvrir depuis Telegram, il faudra ensuite :
1. Déployer le site sur un hébergement HTTPS.
2. Configurer l'URL de la Mini App pour @companymenu_bot via BotFather.
3. Ajouter la validation serveur des données Telegram avant toute fonction de compte/commande.

IMPORTANT :
- Ne mets jamais le token du bot dans le code du navigateur.
- Cette base est une maquette fonctionnelle de navigation, pas encore une boutique avec commandes, stock ou paiement.
- Avant toute vente, vérifie les règles applicables aux produits CBD, à Telegram et au prestataire de paiement.
- Les zones tactiles superposées à l'image sont approximatives et devront être ajustées/testées sur mobile.
